# FAHMX® — Creative Portfolio

A responsive, animated portfolio built with plain HTML, CSS and JavaScript.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in your browser, or use the VS Code Live Server extension.
3. Edit `index.html` to update your name, project titles, descriptions, email and social links.
4. Edit `style.css` to change colors, typography and layout.
5. Edit `script.js` to adjust interactions.

## Personalize before publishing
- Replace `hello@example.com` with your real email.
- Replace Instagram and Behance links with your own profile links.
- Replace the concept projects with real work and accurate descriptions.
- The project artwork is created with CSS shapes, so no local image assets are required.
- Google Fonts are loaded online; the page still has fallback fonts if they fail.

This is inspired by bold editorial creative portfolios, not a copy of the referenced website.
