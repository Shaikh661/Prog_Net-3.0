Prog-Net 2.0

Prog-Net 2.0 marked the next stage in the project's evolution, bringing a shift from C-based applications to Java Swing development. Building on the experience gained from the first generation, this version introduced a more structured application environment and a more organized way of combining games and utilities through a centralized lobby.

Documentation pageDetails subject to confirmation

#A New Generation

With Prog-Net 2.0, the project entered a new development phase. The decision to move to Java introduced a different programming environment and an opportunity to work with object-oriented concepts and graphical application development. The central idea of connecting multiple applications through a lobby remained, but the implementation evolved. Using Java Swing, the team developed a launcher-style application that brought different games and utilities into one interface.

i

The core lobby concept was carried forward, but its technical implementation changed as the project grew.

#Games, Utilities, and Lobby

Prog-Net 2.0 expanded the original concept of a centralized application hub. Instead of focusing on a collection of smaller C-based programs, this generation brought together multiple games and utilities developed as Java applications. The lobby served as the main entry point, allowing users to select and launch different modules through a unified interface. Each module had its own functionality while remaining part of the larger Prog-Net environment.

i

The lobby became a more organized and visual gateway to the project’s modules.

#Major Improvements

From individual programs to a unified application: Prog-Net 2.0 introduced better organization, a Java Swing interface, and more structured navigation. The lobby became more than a simple selection screen; it served as the central point from which users could access different games and utilities. CardLayout allowed multiple screens and modules to work within a single application window, creating a more consistent user experience. The project’s scope also expanded with larger modules such as Minecraft 2D, which added player movement, map editing, and world interaction.

i

The second generation focused on structure, navigation, and a more connected application experience.

#Lessons Learned

Prog-Net 2.0 taught us that moving to a new programming language is not simply about learning different syntax. It also means adapting to new ways of organizing code, designing interfaces, and approaching problems. Working with Java Swing introduced us to graphical application development and gave us practical experience with object-oriented programming. The project also showed us how a centralized application could bring multiple independent modules together in a more organized way.

i

The second generation prepared the team for the broader, product-focused direction of Prog-Net 3.0.
